# RE.SOURCE — ROTEIRO MANUAL FINAL DO MVP (DIA 6)

Objetivo: validar o caminho completo da apresentacao sem alterar o banco
manualmente durante o fluxo. O nome do arquivo foi mantido por compatibilidade.

Use um navegador normal para a Empresa A, uma janela anonima para a Empresa B
e outro perfil/janela para o administrador.

===============================================================================
0. PREPARACAO MANUAL
===============================================================================

[ ] Apache e MariaDB estao ativos no XAMPP.
[ ] O repositorio esta na main e recebeu o ultimo pull.
[ ] O .env local existe e nao esta rastreado pelo Git.
[ ] Confirmar no .env: DB_DATABASE=resource.
[ ] Criar um banco resource vazio e seleciona-lo no phpMyAdmin.
[ ] Importar database/seeders/re.sourcebanco.sql.
[ ] Importar database/inserts/create_admin.sql.
[ ] Se quiser dados prontos, importar em seguida empresa_demo.sql, produto.sql
    e saldo_demo.sql, exatamente nessa ordem.
[ ] No phpMyAdmin, confirmar que o banco resource possui 30 tabelas.
[ ] Confirmar a existencia das tabelas withdrawals, financial_transactions,
    freight_quotes, freights, freight_status_history e delivery_attempts.
[ ] Confirmar que existem usuarios admin e duas empresas ativas para o teste.
[ ] Confirmar que existem pelo menos dois anuncios de empresas diferentes.
[ ] Reiniciar Apache se a configuracao do .env tiver sido alterada.
[ ] Abrir http://localhost/re.source e confirmar que nao ocorre erro 500.

Resultado esperado: banco resource atual preservado e pronto para teste manual.
